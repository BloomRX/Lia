LEIA-ME — Projeto Lia
======================

Lia é uma waifu virtual com voz personalizada e integração com IA.

COMO USAR (primeira vez):
  1. Rode app\LiaAppInstaller.bat (instala Python deps)
  2. Rode waifu.bat (abre o app desktop)
  3. No app: "🎤 Treinar Local" para treinar voz personalizada

ESTRUTURA:
  app/
    lia_app.py           ← App principal (interface + treinamento)
    installer.py         ← Script de instalação
    LiaAppInstaller.bat  ← Instalador rápido

  scripts/
    train_auto.py        ← Pipeline de treinamento automatizado
    servidor_voz_airi.js ← Servidor TTS (Edge + Kokoro offline)
    *.ps1                ← Scripts PowerShell auxiliares

  colab/
    AgentAI.ipynb        ← Notebook do Colab (cérebro IA)

  docs/
    ESTADO-DO-PROJETO.txt ← Estado completo do projeto
    persona-lia.md        ← Persona da Lia
    LEIA-ME.txt           ← Este arquivo

  waifu.bat              ← Launcher principal

TREINAMENTO DE VOZ:
  - 100% automático: slice → ASR → BERT → HuBERT → SV → SoVITS → GPT
  - Selecione pasta com áudios e aguarde (~85 min em CPU)
  - Modelo final em sovits-data/GPT-SoVITS/{nome}/
  - Resume automático se interrompido

SERVIDOR DE VOZ:
  - Interface web: http://localhost:9860/
  - Engines: Edge (online) e Kokoro (offline, ~360 MB)
  - Ajustes: pitch, velocidade, teste em tempo real
  - Vozes recomendadas: Thalita, Brenda, Francisca, Nanami

COLAB (CÉREBRO IA):
  - Abra colab/AgentAI.ipynb no Google Colab
  - Runtime: T4 GPU
  - URL do túnel salva no Google Drive

REQUISITOS:
  - Windows 10/11
  - Python 3.10+ (winget install Python.Python.3.12)
  - Node.js 18+ (servidor de voz)
  - Git (clonar GPT-SoVITS)
  - Google Colab com T4 (cérebro IA)
