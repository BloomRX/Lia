1) O QUE O PROJETO E (arquitetura atual)
--------------------------------------------------------------------
  [Desktop] Lia App = painel desktop (CustomTkinter) que:
    - Gerencia modelos de voz (GPT-SoVITS v2Pro)
    - Treina modelos automaticamente (pipeline completo)
    - Sintetiza voz (TTS) com modelos treinados
    - Interface: app/lia_app.py (v50)

  [Pipeline] scripts/train_auto.py = treinamento automatizado:
    - Etapa 0: Instala dependencias do venv
    - Etapa 1: Slice de audio (slicer2)
    - Etapa 2: ASR (Faster Whisper, large-v3, auto-detect)
    - Etapa 3: Fix idioma (PT→EN) + NLTK download
    - Etapa 4: Dataset (BERT + HuBERT + SV embeddings)
    - Etapa 5: SoVITS (8 epochs default, CPU ~85min)
    - Etapa 6: GPT (20 epochs default)
    - Resume automatico (retoma de onde parou)

  [GPT-SoVITS] Repo na maquina do usuario:
    J:\AIRI_Collab\sovits-data\GPT-SoVITS
    - v2Pro (versao mais recente)
    - Modelos pretrained em GPT_SoVITS/pretrained_models/
    - Logs em logs/<model_name>/
    - Pesos em SoVITS_weights_v2Pro/ e GPT_weights_v2Pro/

--------------------------------------------------------------------

    (proxy corporativo bloqueia downloads sem isso)

  - HuBERT: SEMPRE rodar model.float() apos get_model()
    (features em float16 causam problemas no treino)

  - SoVITS v2Pro: gin_channels=1024 (NAO 512)
    (pretrained model espera 1024, causa size mismatch)

  - Checkpoint dirs: SEMPRE criar logs_s2_v2Pro/ e logs_s1_v2Pro/
    ANTES de iniciar treino (Windows os.rename falha sem diretório)

  - BERT output: SEMPRE renomear 2-name2text-0.txt -> 2-name2text.txt
    (SoVITS espera esse nome especifico)

  - SV embeddings: Re-verificar apos limpeza HuBERT
    (has_sv fica stale se HuBERT limpa os arquivos)

  - Windows paths: usar os.path.join() sempre
    (barra invertida vs barra normal)

  - sandbox: reset apaga node_modules e mata processos
    (reiniciar servers apos reset)
